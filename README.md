# github-changelog-translator

[GitHub Changelog](https://github.blog/changelog/) の RSS フィードから、タイトルと本文を翻訳した RSS を自動で配信します。

現在、GitHub Pages で配信しているのは日本語に翻訳したもののみです。

## RSS の利用方法

翻訳済みの RSS は GitHub Pages で配信しています。以下の URL を購読してください。

https://book000.github.io/github-changelog-translator/changelog.xml
